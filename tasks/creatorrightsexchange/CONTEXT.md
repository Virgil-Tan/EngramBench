# CreatorRightsExchange Domain Language

- **UploadSession**: the resumable authority for one exact media byte sequence.
- **BlobObject**: the quarantined or ready immutable media object created by completion.
- **Edition**: a published immutable manifest of assets, renditions, and one frozen rights revision.
- **LicenseOffer**: the versioned commercial terms for one published Edition.
- **PurchaseOrder**: the frozen risk/payment workflow that may create one License.
- **EntitlementGrant**: the strongly consistent access authority derived from a License.
- **RoyaltyEntry**: one immutable debit or credit inside a balanced posting.
- **RightsDispute**, **LicenseHold**, and **RoyaltyAdjustment**: the single Manager extension revealed only after V1 review.

Use these terms consistently across README, dialogue, evaluator, checklist, and reports. The system is one media-to-commerce lifecycle, not five independent applications.
