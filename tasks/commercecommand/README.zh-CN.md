# CommerceCommand 超大型 Transfer Task

CommerceCommand 是四个新增 Transfer 项目中规模最大的一个。它把前 30 个 Learning Task 中可迁移的工程能力放进同一条全渠道交易主流程，而不是把互不相关的页面拼在一起。

## 测量目标

1. 不可变报价版本和下单时冻结；
2. 多库存池并发守恒与补偿；
3. 支付未知响应、乱序回调、退款和重放；
4. 多 Worker lease/fencing、崩溃恢复和确定性履约；
5. 数字权益撤销、事务账本和可靠通知；
6. 多租户安全边界、兼容迁移和蓝绿运行；
7. Manager 中途加入 marketplace 分账、结算、争议和跨周期调整。

## 规模

- 32 个真实开发 Scene，最低 40 轮、最高 90 轮；
- H-01～H-30，共 30 个独立黑盒测试；
- 10 条持续压力场景；
- 两个 API、多 Worker、多 dispatcher、未知响应、SIGKILL、迁移和灾难恢复组合；
- 公开合同包含所有产品规则，隐藏测试只改变数据、并发交错和崩溃时点。

预计一次完整真实交互、实现、项目测试和隐藏测试约需要 6 小时。
